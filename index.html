03 — Process

How I work

A repeatable system, not a rigid formula — adapted to the ambiguity of each problem.

FRAME

Define the real problem

Align on constraints, users, and success metrics before any pixels exist.

MAP

Design the system

Sketch the underlying logic — states, flows, and edge cases — as a system.

SHAPE

Craft the surface

Bring precision to typography, spacing, and motion once the logic holds.

PROVE

Validate & iterate

Test with real users, measure impact, and refine the system in production.
